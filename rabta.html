The digital bridge between parents, teachers, and school. Bilingual English / اردو end-to-end.

View Live Demo → View on GitHub →

1. Project Overview

Rabta (رابطہ — "connection" in Urdu) is a cross-platform Flutter app that connects parents and teachers with their school. Parents track progress, view reports, and raise concerns. Teachers post attendance, update grades, publish exams and notices, and handle parent requests.

How it works

  • Welcome screen: pick Parent or Teacher role and toggle English / Urdu
  • Parents see child summary, subject progress, report cards, exam schedule, notices, and request forms
  • Teachers mark attendance, enter grades, post exams and announcements, and review parent concerns
  • All demo flows run on rich mock data — no account or backend required to explore
  • Supabase is wired for optional real backend integration with RLS-backed tables

4. Parent Portal

  • Dashboard — child summary card and five quick-action tiles
  • Progress — attendance-style subject bars across Week / Month / Term
  • Reports — published report cards with per-subject scores
  • Exam schedule — upcoming exams with date, time, and room
  • School notices — announcements from the school
  • Parent requests — raise a concern (teacher, conduct, facilities) or book a head meeting

5. Teacher Portal

  • Dashboard — class overview with colour-coded action tiles
  • Mark Attendance — present/absent toggles with live counter and "All present" shortcut
  • Update Grades — subject chip + period selector; grade entry via bottom sheet
  • Post Exam Date — subject, date picker, optional time, room field
  • Post Notice — title + body with live preview card
  • Parent Requests — expandable cards for concerns and meeting proposals

6. Localization

Every heading, label, chip, and date format is available in both English and Urdu via RabtaStrings and TeacherStrings. The chosen language persists across app restarts and flows through the entire navigation stack.

7. Deploy & CI/CD

Web (Vercel): Vercel runs scripts/vercel_build.sh to compile Flutter web; SPA rewrites via vercel.json.

Android: GitHub Actions builds a release APK on every push to main — download from Actions → Artifacts → rabta-release-apk.

Supabase (optional): Pass SUPABASE_URL and SUPABASE_ANON_KEY at build time to enable real backend reads/writes.

8. How to Run Locally

git clone https://github.com/wasimahmadpk/rabta.git
cd rabta
flutter pub get
flutter config --enable-web
flutter run -d web-server   # or: flutter run -d chrome

Production web build: flutter build web --release → serve build/web
