MedX

Hybrid Medical Content Recommender · Author: Wasim Ahmad · github.com/wasimahmadpk/MedX

The right medical article, for the right doctor, at the right time.

View Live Demo → API Docs →

1. Project Overview

MedX is a deployable hybrid medical content recommender for HCP-style feeds. It combines TF-IDF content filtering, SVD collaborative filtering, synthetic event-log features, and a learned ranker — served through a carousel UI and REST API on Vercel.

Doctors are overloaded with literature. MedX answers three questions for every article:

SignalQuestionMethod
RelevanceDoes this fit the doctor's specialty?TF-IDF + cosine similarity
BehaviourDo peers with similar tastes read this?SVD matrix factorisation
TimingCan they read it now?Context features + log patterns by hour

How it works

  • Pick a doctor and fetch personalised recommendations (top 3 articles)
  • Content scores from TF-IDF; collaborative scores from mean-centred NumPy SVD
  • 15 log-derived features feed a learned ranker (sklearn GBR on Vercel)
  • Time-of-day rules boost lunch-friendly short reads vs evening deep dives
  • Drag the α slider to shift content vs collaborative weight in real time

4. Recommendation Pipeline

StageAlgorithmRole
1. ScoringTF-IDF + SVDRelevance signals per article
2. Features15 log + content fieldsRanker input
3. Rankingsklearn GBR (prod) / LightGBM (local)Final list order
4. Fallbackα-blend × context boostWhen ranker off or no hour
 
features  = content, collab, α, specialty_match, complexity, read_time,
            context_boost, hour, log aggregates, dwell, …
ranker    = sklearn GBR(features)  →  top 3
fallback  = α·content + (1−α)·collab  ×  context_boost(hour)

7. Dataset

Synthetic data for the PoC: 15 doctors, 40 articles, 94 ratings, and 319 event logs (impressions, clicks, reads with hour and dwell time).

8. How to Run Locally

git clone https://github.com/wasimahmadpk/MedX.git
cd MedX
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload

Open localhost:8000 · API docs at /docs
